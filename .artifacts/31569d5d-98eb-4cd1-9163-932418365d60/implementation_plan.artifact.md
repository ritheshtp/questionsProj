# Fix for "kotlin.sourceSets DSL not allowed" Error

The error `Using kotlin.sourceSets DSL to add Kotlin sources is not allowed with built-in Kotlin` occurs because the **Android Gradle Plugin (AGP) 8.0+** (and especially the version `9.3.1` you are using) now manages Kotlin source sets directly. It prohibits the use of the legacy `kotlin.sourceSets` DSL, which was previously used to add source directories (like those generated by KSP or Hilt).

Even though your `build.gradle.kts` files don't explicitly use this DSL, plugins like **KSP** or **Hilt** might be using it internally to register their generated code.

## Proposed Changes

### [gradle.properties](file:///Users/rithesh/questions/gradle.properties)

#### [MODIFY] [gradle.properties](file:///Users/rithesh/questions/gradle.properties)
- Add `android.disallowKotlinSourceSets=false` to suppress this strict check and allow plugins to use the legacy DSL for source set configuration.

### [app/build.gradle.kts](file:///Users/rithesh/questions/app/build.gradle.kts)

#### [MODIFY] [app/build.gradle.kts](file:///Users/rithesh/questions/app/build.gradle.kts)
- Update `compileSdk` to 37.
- Update `targetSdk` to 37.
